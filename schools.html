In class

Set up in five minutes.

1

Teacher makes a class

Open the dashboard, sign in with your school email, and create a class. You get a 6-letter code. Show it on the projector.

2

Students join

They install Think First for Schools, open Class, type the code and their name, and agree to what's shared.

3

Start class

Press Start class on the dashboard. While it's live, every time a student asks an AI, Noodle asks them to try first, and you see who did. Outside class, nothing is shared.

Privacy

Numbers, not words.

Teachers see habits, not homework, and only during class. Students see exactly this list before they join.

The teacher sees, only while class is live

  • When a question was asked
  • Whether the student tried first or skipped
  • The subject, like Biology
  • Which AI, and whether it was the app or a website
  • How many words they wrote (not the words)
  • How many points they got or missed (counts only)

Never leaves the Mac

  • Anything outside class time: evenings, weekends, other lessons
  • The questions
  • What the student wrote
  • The AI's answers
  • Chat or window titles
  • Screenshots
  • Anything from before they joined

Questions

Good to know.

Is it the same app as Think First?

It's a separate app, with its own icon and its own data. Students who already use Think First keep their personal app untouched. Think First for Schools adds the Class page; everything else, including Noodle, works the same.

Can students leave?

Yes, any time, from the Class page. They can also delete everything they shared. Teachers can remove students from a class too.

Does it see AI websites, or only apps?

Both: the ChatGPT, Claude, Gemini and Perplexity apps, and AI chat websites in Safari, Chrome, Arc, Edge, Firefox and other browsers.

Does it share what students do at home?

No. Sharing only happens while you've started class from the dashboard, and it ends automatically when the time is up. Questions asked at home, at weekends or in other lessons never leave the student's Mac, and the database refuses them even if something went wrong.

What if a student quits the app?

Then nothing is counted while it's closed. The dashboard shows when Think First was last active for each student, so you can tell.

Does it cost anything?

It's free during the pilot.

Where is the data stored?

The numbers are stored on a class server run with Supabase. Only the teacher who owns a class can see that class. Questions and answers never leave the student's Mac. Please check with your school before using it with a class.
